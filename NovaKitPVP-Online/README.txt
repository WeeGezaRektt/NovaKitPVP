NovaKitPVP — Minecraft Font Patch

Replace these files in NovaKitPVP-Online:
- index.html
- admin.html
- tournament.html

Add:
- minecraft-font.css

This applies the Minecraft font to the full public rankings site, staff portal,
tournament page, buttons, inputs, labels, badges, popups, and generated text.

No font file is bundled in this patch. The CSS loads the webfont from CDNFonts.

GitHub's connected integration is currently rejecting writes with HTTP 403,
so these files are prepared for manual upload.
